# user-keyboard-shy

*The user says they're bad with a keyboard, so nothing in the game should depend on fast or accurate typing*

The user said "i suck with my keyboard", after accidentally cancelling several requests. They also asked for console-style hacking in skill check windows.

On 2026-11-05 they asked for WASD movement themselves, so keyboard play they ask for is welcome, as long as clicking still does everything and nothing is timed on typing (the clock stops while there's text in the typing line).

**Why:** a game that punishes typos or fast typing would shut out the person it's being built for.

**How to apply:** anything interactive must work by clicking too, with no time limits on typing, and typed commands should forgive typos and partial words. See [user-no-coding-experience](user-no-coding-experience.md) and [project-last-meridian](project-last-meridian.md).
