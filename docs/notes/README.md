# Notes on the project

What was decided and why, written as the work went on, up to 2026-11-02. Each note says what was true when it was written, so check it against the code before relying on it. The code records what was built, and these record what the owner asked for, in their own words where that matters.

- [project-app](project-app.md): The game (Almagest Explorer's, The Last Meridian until 2026-11-08) as an installed Windows app (Electron), built 2026-11-01. How game changes reach it, and what that means for restarting and testing
- [project-fleet-layer](project-fleet-layer.md): The fleet layer, built 2026-11-01 and removed 2026-11-08 at the owner's word: the game is about the Meridian alone now (src/ship.js, world/ship.json, save version 16), with the Sundial and Anselm's Mercy kept as places of their own and the raids dropped
- [project-github](project-github.md): The game is on GitHub twice since 2026-11-02: private chamer2011/the-last-meridian so the player can carry on elsewhere, and public chamer2011/last-meridian with only the game, for feedback. What's in each, and that nothing uploads by itself
- [project-inventory](project-inventory.md): The grid inventory on I: their pick (B with C's locker, smaller) built on 2026-11-06 and untried by them, with new rules they haven't confirmed (belt-only supplies in fights, a sidearm to draw, a load limit, loot piles)
- [project-last-meridian](project-last-meridian.md): Almagest Explorer's (The Last Meridian until 2026-11-08), the user's sci-fi AI RPG, and the look and references they've asked for
- [project-logistics](project-logistics.md): The ship's logistics, asked for on 2026-11-08: nothing from nothing (garden → pantry → kettle → people; fuel cells → generator → fixed power for the systems; people carry from the shuttle stores, which refill from nothing until trade is simulated); a seven-step plan on a page they tick off, built one step at a time after their test; not yet built
- [project-menus](project-menus.md): The menus tidied on 2026-11-02 at the owner's request: seventeen entries grouped under five headings on the rail, long sections folded behind [ + ] lines, three entries renamed, and no explaining text under the names, which they asked for
- [project-next-update](project-next-update.md): The owner's big update after 0.3.0 (announced 2026-11-05): three points agreed and on a plan page; all three are built (hacking, a usable system on every computer, each place's own systems) and untried by them
- [project-optional-ai](project-optional-ai.md): Their next direction, from 2026-11-02: the game playable with or without an API key, in the genre of Age of Decadence and Colony Ship, with the AI as an optional layer. The seven-step plan I proposed, and no GitHub updates until they've tested
- [project-quests](project-quests.md): The quest system asked for on 2026-11-06: tracker C at the top left that J grows into the quest log, no story along the bottom, scenes that go on only with the person they need, on hold when you walk away, failed if that person dies; built the same day and untried by them
- [project-story-popups](project-story-popups.md): The story as popups over the isometric room, the player's pick (example D, speech over people's heads) with their three tweaks, plus interface size and full screen. Built 2026-11-02, backup before-story-popups-2026-11-02. Not yet played by them or run with real Claude
- [project-tiled](project-tiled.md): The pre-rendered direction they chose on 2026-11-08: rooms drawn in Tiled first (src/tiled.js, the same day), then the ship redrawn as three continuous decks at their 'One map per deck' (deck1/2/3.tmj, rooms as rectangles on a deck, laid out after the Anvil Carrack as a starting point for them to redraw), then their own pictures with the game's lighting, then a Blender camera setup; untried by them
- [project-walk-around](project-walk-around.md): The Last Meridian's walk-around view: every part of all 24 places is its own level, with closed doors that only the story opens, and invented places get drawn rooms. Built 2026-11-01, not yet run with real Claude
- [project-world-engine](project-world-engine.md): The player's long-term plan for The Last Meridian: a living world where they aren't the main character, built in steps, with fights kept as they are. All 6 steps went in by 2026-11-02, and they chose the isometric look for step 6, which the game now opens in
- [user-keyboard-shy](user-keyboard-shy.md): The user says they're bad with a keyboard, so nothing in the game should depend on fast or accurate typing
- [user-no-coding-experience](user-no-coding-experience.md): The user has no coding experience, so explain results in plain language and handle all technical steps for them
