# Notes on the project

What was decided and why, written as the work went on, up to 2026-11-02. Each note says what was true when it was written, so check it against the code before relying on it. The code records what was built, and these record what the owner asked for, in their own words where that matters.

- [project-app](project-app.md): The Last Meridian as an installed Windows app (Electron), built 2026-11-01. How game changes reach it, and what that means for restarting and testing
- [project-fleet-layer](project-fleet-layer.md): The Last Meridian's fleet command layer, built 2026-11-01, what's untested with real Claude, and what's left for later steps
- [project-github](project-github.md): The game is on GitHub twice since 2026-11-02: private chamer2011/the-last-meridian so the player can carry on elsewhere, and public chamer2011/last-meridian with only the game, for feedback. What's in each, and that nothing uploads by itself
- [project-last-meridian](project-last-meridian.md): The Last Meridian, the user's sci-fi AI text RPG, and the look and references they've asked for
- [project-story-popups](project-story-popups.md): The story as popups over the isometric room, the player's pick (example D, speech over people's heads) with their three tweaks, plus interface size and full screen. Built 2026-11-02, backup before-story-popups-2026-11-02. Not yet played by them or run with real Claude
- [project-walk-around](project-walk-around.md): The Last Meridian's walk-around view: every part of all 24 places is its own level, with closed doors that only the story opens, and invented places get drawn rooms. Built 2026-11-01, not yet run with real Claude
- [project-world-engine](project-world-engine.md): The player's long-term plan for The Last Meridian: a living world where they aren't the main character, built in steps, with fights kept as they are. All 6 steps went in by 2026-11-02, and they chose the isometric look for step 6, which the game now opens in
- [user-keyboard-shy](user-keyboard-shy.md): The user says they're bad with a keyboard, so nothing in the game should depend on fast or accurate typing
- [user-no-coding-experience](user-no-coding-experience.md): The user has no coding experience, so explain results in plain language and handle all technical steps for them
